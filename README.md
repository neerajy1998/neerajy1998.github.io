# Neeraj Kumar Yadav - Portfolio

Personal portfolio website for **Neeraj Kumar Yadav**, Ph.D. scholar in Computer Science and Engineering at IIIT-Delhi, built on the portfolio template by [Swapnil Bhaye](https://github.com/swapnilbhaye).

## Sections
- Hero with animated typing intro
- About, Skills, Education, Experience, Projects
- Achievements & Awards
- Contact (email + CV download)

## Run locally
Just open `index.html` in a browser, or serve the folder:
```
python3 -m http.server 8000
```

## Deploy on GitHub Pages
1. Push this repo to your GitHub account.
2. Repo Settings -> Pages -> Source: deploy from the `main` branch, root folder.
3. Your site goes live at `https://<username>.github.io/<repo-name>`.
4. Update the canonical link comment in `index.html` and the URL in `sitemap.xml` with the live address.

## Edit
All content lives in `index.html` (plain HTML + Tailwind). Resume PDF is at `assets/Neeraj_Kumar_Yadav_CV.pdf`.
